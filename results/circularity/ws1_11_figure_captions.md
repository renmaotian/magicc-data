### ws1_11_fig1_signed_error_by_arm

Signed error (predicted − true, percentage points) of each tool on set_H_ncbi, split by whether the reference genome would have PASSED ("pass", n=2000 simulations from 200 references) or FAILED ("FAIL", hatched, n=2000 from 200 references) the project's CheckM2-based curation filter. Violin = kernel density, box = median and IQR with 1.5xIQR whiskers, marker = mean. Arms are matched 1:1 by taxonomy and genome size and share identical target draws. Colour is CVD-safe and always redundant with position, marker and hatch. Denominators: completeness (%) = retained dominant-genome bp / full reference length of the dominant genome x 100; contamination (%) = total contaminant bp / full reference length of the dominant genome x 100. Both percentages use the same denominator (the full reference length of the dominant genome) and are therefore independent measures; contamination is not normalised to total assembly length or to retained dominant length.

### ws1_11_fig2_paired_arm_difference

Primary WS1.11 estimator. D is the mean per-sample difference in absolute error between a reference the CheckM2-based curation would have rejected and its taxonomically matched, size-matched accepted control, on simulations that share identical target completeness/contamination draws. Bars are 95 % cluster-bootstrap CIs resampling the 200 matched reference pairs (2000 paired simulations per tool per metric, 2,000 replicates). D > 0 means the tool is worse on the genomes the curation removed. Denominators: completeness (%) = retained dominant-genome bp / full reference length of the dominant genome x 100; contamination (%) = total contaminant bp / full reference length of the dominant genome x 100. Both percentages use the same denominator (the full reference length of the dominant genome) and are therefore independent measures; contamination is not normalised to total assembly length or to retained dominant length.

### ws1_11_fig4_reference_incompleteness_mechanism

Per-reference mean signed completeness error against how far the reference genome fell below the curation filter's 98 % CheckM2-completeness criterion, over all 400 references (10 simulations each; filled = the 200 would-have-FAILED references, open = their 200 matched controls, which sit at deficit 0 by construction). The benchmark defines completeness relative to the deposited assembly, so a reference that is genuinely incomplete makes any biologically calibrated estimator read low; a negative slope therefore indicates the truth definition moving, not the estimator failing. For MAGICC the x axis is independent evidence (MAGICC never sees a CheckM2 score); for CheckM2 the x axis is its own estimate, so its slope is circular by construction and is shown only for contrast. Denominators: completeness (%) = retained dominant-genome bp / full reference length of the dominant genome x 100; contamination (%) = total contaminant bp / full reference length of the dominant genome x 100. Both percentages use the same denominator (the full reference length of the dominant genome) and are therefore independent measures; contamination is not normalised to total assembly length or to retained dominant length.

### ws1_11_fig5_threshold_5pct_false_fail

False-fail rate at the MIMAG-inspired 5 % contamination boundary: the fraction of truly clean simulations (<5 % contamination) that a tool calls contaminated. Denominators are the truly clean simulations only — n=96 in the would-have-passed arm and n=98 in the would-have-FAILED arm (hatched). Bars are 95 % cluster-bootstrap CIs over reference genomes. False-fail rate must be read together with the false-pass rate in ws1_11_thresholds.tsv: a tool can buy a low false-fail rate by barely calling contamination at all. Denominators: completeness (%) = retained dominant-genome bp / full reference length of the dominant genome x 100; contamination (%) = total contaminant bp / full reference length of the dominant genome x 100. Both percentages use the same denominator (the full reference length of the dominant genome) and are therefore independent measures; contamination is not normalised to total assembly length or to retained dominant length.
