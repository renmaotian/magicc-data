**Set F — contamination type x taxonomic distance.** Denominator of every cell: n = 1800 contaminated samples per tool (100 reference genomes x 6 taxonomic distances x 3 contamination types; 100 samples per cell). Colour is the mean signed error (predicted - true) in percentage points; negative (blue) = under-estimate. Confidence intervals are cluster bootstrap (2000 resamples) over reference genomes. Denominators: completeness = retained dominant bp / dominant full reference bp x 100; contamination = total contaminant bp / dominant full reference bp x 100. Both are percentages of the SAME denominator (the dominant genome's full reference length), so they are independent and contamination can exceed 100% in principle.
